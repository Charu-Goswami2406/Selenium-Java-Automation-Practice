# Selenium Java Automation Practice

This repository contains my Selenium WebDriver automation practice using Java, Maven, TestNG/JUnit, and Page Object Model.

## Tech Stack
- Java
- Selenium WebDriver
- Maven
- TestNG / JUnit
- Eclipse IDE
- Git & GitHub

## Topics Covered
- Browser launch
- Locators: id, name, className, linkText, partialLinkText, xpath, cssSelector
- WebElement actions
- Dropdown handling
- Radio buttons and checkboxes
- Alerts
- Waits
- Screenshots
- Page Object Model
- Test reports
